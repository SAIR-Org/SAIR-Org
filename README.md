## 🌐 Why We Expanded Beyond Sudan

SAiR began as a response to one specific gap: Sudan has enormous technical talent and almost no structured, free path into modern AI engineering. As the first cohorts grew, three things became obvious:

1. **The gap is regional, not national.** Learners from other African and Middle Eastern countries facing the exact same problem started asking to join.
2. **The curriculum was already region-agnostic.** Tokenizers, attention, training loops — none of it requires Sudanese context to teach or to learn. It travels.
3. **A bigger community compounds.** More learners means more peer mentors, more project diversity, and a stronger case to universities, employers, and funders that this pipeline works at scale.

So we're stating it plainly: **SAiR is Sudanese-founded, but not Sudan-only.** Sudan is the origin story and a permanent home base — not a ceiling.

| | Before | Now |
|---|---|---|
| **Who it's for** | Sudanese AI enthusiasts | Learners across Africa, the Middle East, and the Global South |
| **Framing** | "Sudan's AI future" | A shared, multi-regional AI future |
| **Structure** | Single, Sudan-based group | Sudan HQ + regional chapters as they form |
| **Language** | Arabic/English (Sudan) | Arabic/English core, open to local-language chapters |

## 🏆 Capstone: miniGPT

<div align="center">

<h3>Build a GPT. Train it. Talk to it.</h3>
<p>A full-stack, hackable GPT playground — from raw text to a live web UI.</p>

<p>
<a href="https://github.com/SAIR-Org/miniGPT"><img src="https://img.shields.io/badge/⭐_Star_on_GitHub-181717?style=for-the-badge&logo=github&logoColor=white" alt="GitHub"/></a>
<img src="https://img.shields.io/badge/Python-3.12%2B-brightgreen?style=flat-square"/>

<img src="https://img.shields.io/badge/tests-39%20passing-success?style=flat-square"/>
</p>

</div>

**Quick start — Modal cloud, 3 steps:**

```bash
# 1. Train on Modal A100 (~3 hrs, ~$12–15)
uv run python -m modal run train/modal_train.py::main

# 2. Download the final checkpoint
uv run python -m modal run train/modal_train.py::download

# 3. Launch the web UI and demo it live
uv run sair ui        # → http://localhost:7860
```

| Feature | What it does |
|---|---|
| 🖥️ `sair` CLI | Go from raw text to trained model in a few commands |
| 📄 Multi-format data | `.txt` and `.pdf` files as training data |
| ☁️ Flexible training | Local CPU/GPU · Modal A100 cloud · multi-GPU DDP |
| 📊 W&B + plots | Live loss curves + PNG saved after training |
| 🌐 Web UI | Chat with your model in the browser |
| 🚀 Pretrained models | Load GPT-2 (124M → 1.5B) without training |

**Real example:** a `medium` preset (~163M params) trained on 6 Harry Potter books for ~$12–15 and ~3 hours on a Modal A100, producing a model that generates coherent Harry Potter-style text.

```
uv run python -m pytest tests/ -v
→ 39 passed in 8.65s
```

```
miniGPT/
├── config.py               ← all hyperparams
├── cli.py                  ← sair prepare | train | generate | ui
├── data/                   ← data preparation & dataset
├── model/                  ← GPTModel: LayerNorm → MHA → FFN → Block
├── train/                  ← trainerV3, DDP, Modal cloud
├── inference/              ← generateV0→V3, weight loading
├── ui/                     ← FastAPI backend + SAIR-branded web UI
├── finetune/               ← SFT for classification & instruction
├── tests/                  ← 39 tests covering full pipeline
└── ui_finetune/             ← fine-tuning web interface
```

### 🔜 Immediate: Module 6 — MLOps

Docker containerization · FastAPI model serving · MLflow experiment tracking · DVC data versioning · GitHub Actions CI/CD · Prometheus & Grafana monitoring. This closes the loop from "I trained a model" to "I run a model in production."

### 🌍 Near-term: First Regional Chapters

Sudan stays HQ. The plan is community-led chapters in interested African and MENA countries, running the same curriculum with local mentors and locally-relevant capstone projects — not a copy-paste of Sudan's context, but the same rigor applied to whatever problem is in front of that chapter's learners.

### 🔬 Near-term: A Research Track (not a standing lab — a roadmap item)

Rather than spinning up a permanent research division before we have the base to support it, research is a scheduled roadmap milestone: a first preprint in Q3 2025, a conference submission by Q4 2025, and journal-track publications from multi-region author teams in 2026. Early candidate areas — chosen because they map to problems our learners actually face, not to trends:

- **Low-resource NLP** — Arabic dialects and other under-resourced languages
- **Healthcare AI** — localized disease prediction
- **Agriculture tech** — climate-smart farming for local conditions
- **Renewable energy** — optimization models for varied grid contexts

### 🚀 Later: Innovation Hub

Once graduates exist in enough regions with enough projects, the Innovation Hub becomes a place to turn capstones into startups, deployed tools, and edge-AI solutions — with the same "build it yourself" ethos that got them there.
